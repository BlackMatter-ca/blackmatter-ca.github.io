# Logos

- `blackmatter-logo.svg` — The wordmark as supplied: ink `logo-ink` (#23161f), triangles `berry`. For light grounds; it vanishes on `base`.
- `blackmatter-logo-clean.svg` — The same mark with the editor's guides and metadata stripped, same colours. Prefer it for the web.
- `blackmatter-logo-on-dark.svg` — The dark-ground edition: the wordmark fill swapped for `text` (#ede1e9), triangles still `berry`. Use on `base`, `mantle` and `crust`.

- `blackmatter-stone.svg` — The stone, as supplied: the A cut as one wedge, ink #1c1119 on an A4 page box. For light grounds.
- `blackmatter-stone-clean.svg` — The stone trimmed to its shape, same ink.
- `blackmatter-stone-on-dark.svg` — The stone in `text` (#ede1e9), for `base`, `mantle` and `crust`.
- `blackmatter-stone-berry.svg` — The stone in `berry` (#fd7ca5): the pink triangle as a mark.

The stone editions are single-ink SVGs with a fixed fill; the wordmark editions are two-ink. All with fixed fills, shown via `<img>`; it does not take CSS color. The wordmark is DIN Alternate Bold, outlined.
